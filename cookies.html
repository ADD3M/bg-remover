Cookie Policy

Last updated: September 25, 2026

This policy explains this site's (the "Site") use of cookies and similar technologies. It is general information, not legal advice — if this Site is operated commercially or in a regulated context, have this reviewed by a qualified professional for your jurisdiction.

The short version

This Site does not use cookies. It sets none itself, and it does not knowingly rely on any third party to set them either. Because we don't use non-essential cookies or similar tracking technologies, we don't show a cookie-consent banner.

What a cookie is, briefly

A cookie is a small piece of data a website asks your browser to store and send back on later visits, typically used to keep you signed in, remember preferences, or track behavior across visits. This Site has no accounts, no preferences to remember, and no tracking, so it has no use for them.

What this Site does store on your device

To be precise about what does touch your device, separate from cookies:

  • Standard browser cache. Your browser caches the Site's own files (HTML, CSS, JavaScript) the same way it caches any website, so repeat visits load faster. This is normal web browsing behavior, not a cookie, and is controlled entirely by your browser's own cache and privacy settings.
  • The background-removal model. The first time you use the background-removal tool, your browser downloads the AI model files it needs and stores them locally, using the Cache Storage API (a browser storage mechanism separate from cookies), so future uses are much faster. It holds no information about you or your images — only the reusable model files themselves. A "Clear cached model" button at the bottom of the tool page lets you remove this at any time.

Neither of these persists any personal information, and both can also be cleared at any time by clearing your browser's cache and site data.

Third parties

The AI model files above are fetched from the jsDelivr content delivery network on behalf of the @imgly/background-removal library this tool uses. That request is a normal file download and, to our knowledge, does not set cookies. See jsDelivr's own privacy policy for details of how they handle these requests.

If this ever changes

If a future version of this Site adds anything that does use cookies — analytics, for instance — this page will be updated first, and a consent banner will be added before any non-essential cookie is set.
